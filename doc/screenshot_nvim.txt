================================================================================
                                                        *screenshot.nvim*

Generate polished code screenshots from inside Neovim with the `carbon-now`
CLI.

Requirements:
  - Neovim 0.10+
  - carbon-now-cli available on $PATH

Commands: >
  :ScreenshotBuffer
      Capture the current buffer.

  :ScreenshotSelection
      Capture the current visual selection. The backend is line-based, so the
      capture includes the full selected lines.
<

Lua API: >
  require("screenshot_nvim").setup({
    output = "clipboard",
  })

  require("screenshot_nvim").capture_buffer()
  require("screenshot_nvim").capture_selection()
<

Configuration keys:
  output
      "clipboard" or "file"

  save_dir
      Required when output = "file"

  filename_format
      os.date-compatible suffix used for saved screenshots

  backend.command
      CLI executable to run. Defaults to "carbon-now"

  backend.timeout
      Timeout in milliseconds for the backend process

  backend.extra_args
      Extra argv entries appended to the carbon-now invocation

Health check:
  Use |:checkhealth| screenshot_nvim to verify the runtime environment.
